# About This Design System

The **Homestuck Design System** is a collection of declaration, design, and component library
packages to be used for Javascript and Typescript projects themed to _Homestuck_ and
_MSPaintAdventures_ use cases.

## 📦 Packages

This design system is composed of the following scoped packages:

| Package                                  | Version                                                                                                                          | Description                                                                                                       |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| [`@homestuck/assets`](./packages/assets) | [![NPM Version](https://img.shields.io/npm/v/@homestuck/svh?style=flat-square)](https://www.npmjs.com/package/@homestuck/assets) | A library of iconic shapes, symbols, and fonts that have made appearances within the _MSPaintAdventures_ lexicon. |
| [`@homestuck/styles`](./packages/styles) | [![NPM Version](https://img.shields.io/npm/v/@homestuck/css?style=flat-square)](https://www.npmjs.com/package/@homestuck/styles) | A library of branded design tokens, exported as both DTCG-compliant JSON data files and CSS files.                |
| [`@homestuck/ui`](./packages/ui)         | [![NPM Version](https://img.shields.io/npm/v/@homestuck/ui?style=flat-square)](https://www.npmjs.com/package/@homestuck/ui)      | A library of primitive UI elements, specialized block components, and supporting hook functions.                  |
