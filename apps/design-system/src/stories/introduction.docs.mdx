# About This Design System

The **Homestuck Design System** is a collection of declaration, design, and component library
packages to be used for Javascript and Typescript projects themed to _Homestuck_ and
_MSPaintAdventures_ use cases.

## 📦 Packages

This design system is composed of the following scoped packages:

| Package                                  | Description                                                                                                       |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| [`@homestuck/tokens`](./packages/tokens) | A library of branded design tokens, exported as DTCG-compliant JSON data files.                                   |
| [`@homestuck/styles`](./packages/styles) | A library of CSS files, exported as both global styles and Tailwind-compatible CSS styles.                        |
| [`@homestuck/assets`](./packages/assets) | A library of iconic shapes, symbols, and fonts that have made appearances within the _MSPaintAdventures_ lexicon. |
| [`@homestuck/ui`](./packages/ui)         | A library of primitive UI elements, specialized block components, and supporting hook functions.                  |
